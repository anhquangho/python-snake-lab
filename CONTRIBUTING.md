# Working on the lab

This repository is a learning project. Keep changes small enough to explain and test.

1. Create a local branch for one exercise or bug.
2. Describe the expected behavior before changing code.
3. Add a regression test for a behavior change, implement it, then run the README checks.
4. For UI changes, play the affected flow in a browser at desktop and mobile sizes, and inspect console/network errors.
5. Update the relevant contract or learning note when behavior changes.

Keep the runtime dependency list short. Do not commit virtual environments, databases, private data, or credentials. Avoid replacing the working scaffold with unfinished TODO implementations. Describe contributions according to the work actually done.
